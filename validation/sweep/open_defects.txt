# validation/sweep/open_defects.txt
#
# The absolute gate (scripts/sweep_accuracy --ulp --register <this file>) says
# "no point above its derived bound". These points ARE above it. They are open
# defects in the library, not slack in the derivation, and they are carried here
# in full rather than absorbed by loosening a tolerance.
#
# Format: <backend> <kind> <op> <point>.  Checked in BOTH directions:
#   a point above bound that is not listed here     -> gate FAILS (new defect)
#   a point listed here that is no longer above it  -> gate FAILS (register rotted)
# So the file can only shrink. Delete lines as fixes land; never add one without
# understanding what it is.
#
# WHAT IS IN HERE:
#
#  c tan, 4 points, FF only  (grid 1648-1651, z = +-1e15 on the real axis)
#      Argument reduction at |x| = 1e15 needs n = x/(pi/2) = 6.37e14, which is
#      49.2 bits and does not fit one FP32 limb. kappa = |x/(sin x cos x)| is
#      2.27e15 there. DD holds n in its 53-bit limb and passes at 7.41x; QF and
#      TF also pass (5.07x, 1.60x) on total precision; FF's 48 bits leave
#      nothing after the amplification and it scores 0.00 digits at 36x bound.
#      NOT YET DERIVED: whether FF's bound should carry the reduction-multiple
#      term explicitly. Until that derivation exists this stays a defect rather
#      than being closed as inherent.
#
# CLEARED (do not re-add without measurement):
#
#  c log / c log10 / c pow, 82 points x 4 backends = 984, and
#  c atanh, 16 points x 3 backends = 48
#      One mechanism: angle() tested its degenerate-axis early-out with
#      `== 0.0`, true of negative zero, so atan2(-0, x<0) returned +pi where
#      C99 requires -pi. Fixed in dd/ff/qf/tf_math.hpp angle().
#
#  c div, 11 points across QF/TF/FF
#      The direct form builds the numerator products a*b, whose lowest word
#      sits at |a|*|b|*2^-24(L-1); below FLT_MIN it is subnormal and the
#      product loses the bottom of the expansion. More words is WORSE: at
#      point 1526 QF scored 2.07e6 ulps where TF scored 0.0275 on identical
#      operands. Fixed by lifting both operands by an EXACT power of two before
#      the unchanged direct path, which leaves the quotient bit-identical.
#      Smith routing was tried and rejected: same fix, 13 regressions.
#
# Counts by cell are printed by the gate itself; the grouping above is the
# diagnosis, and the per-mechanism history is in docs/history/KNOWN_ISSUES.md.
#
